# Quick Copy Alt+C

Быстрое копирование выделенного текста по Alt+C с историей копирований.

## Возможности

-  Мгновенное копирование по Alt+C
- 📜 История последних 50 копирований
- 🔔 Уведомления о успешном копировании
- 🌐 Работает на всех сайтах
- ⌨️ Alt+V — просмотр истории
- 🗑️ Очистка истории в один клик
- 🖱️ Перетаскиваемая панель истории

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Alt+C | Скопировать выделенный текст |
| Alt+V | Открыть панель истории |
| Escape | Закрыть панель истории |

## Установка

1. Установите Tampermonkey из магазина браузера
2. Перейдите по ссылке установки
3. Нажмите "Установить"
